CHEMICAL REACTION Jab ek ya ek se adhik substances react karke naye substances banate hain, use Chemical Reaction kehte hain. Example: Magnesium + Oxygen → Magnesium Oxide 2Mg + O2 → 2MgO Reactants = Reaction mein participate karne wale substances. Products = Reaction ke baad banne wale substances. ================================================== SIGNS OF A CHEMICAL REACTION Chemical reaction hone par following changes ho sakte hain: Change in state Change in colour Evolution of gas Change in temperature Formation of precipitate Example: Zn + H2SO4 → ZnSO4 + H2 Is reaction mein Hydrogen gas release hoti hai. Another example: Fe + CuSO4 → FeSO4 + Cu Ismein blue CuSO4 solution ka colour change hota hai. ================================================== CHEMICAL EQUATION Chemical reaction ko chemical symbols aur formulae ki help se represent karna Chemical Equation kehlata hai. Word equation: Magnesium + Oxygen → Magnesium Oxide Chemical equation: Mg + O2 → MgO Balanced equation: 2Mg + O2 → 2MgO ================================================== BALANCED CHEMICAL EQUATION Jis chemical equation mein reactants aur products dono sides par har element ke atoms ki number equal ho, use Balanced Chemical Equation kehte hain. Example: Unbalanced: H2 + O2 → H2O Balanced: 2H2 + O2 → 2H2O IMPORTANT: Equation balance karte waqt chemical formula ke subscripts ko change nahi karna chahiye. Sirf coefficients change karne chahiye. ================================================== TYPES OF CHEMICAL REACTIONS Main types: Combination Reaction Decomposition Reaction Displacement Reaction Double Displacement Reaction Oxidation Reaction Reduction Reaction Redox Reaction ================================================== COMBINATION REACTION Jab two or more substances combine hokar only one product banate hain, use Combination Reaction kehte hain. General form: A + B → AB Example 1: 2Mg + O2 → 2MgO Example 2: CaO + H2O → Ca(OH)2 Example 3: C + O2 → CO2 Example 4: 2H2 + O2 → 2H2O Example 5: Respiration C6H12O6 + 6O2 → 6CO2 + 6H2O + Energy ================================================== DECOMPOSITION REACTION Jab ek compound break hokar two or more simpler substances banata hai, use Decomposition Reaction kehte hain. General form: AB → A + B DECOMPOSITION KE TYPES: A. Thermal Decomposition B. Electrolytic Decomposition C. Photochemical Decomposition A. THERMAL DECOMPOSITION Heat dene par compound break hota hai. Example 1: CaCO3 --heat--> CaO + CO2 Example 2: 2Pb(NO3)2 --heat--> 2PbO + 4NO2 + O2 B. ELECTROLYTIC DECOMPOSITION Electricity ki help se compound decompose hota hai. Example: 2H2O --electricity--> 2H2 + O2 Water → Hydrogen + Oxygen Hydrogen : Oxygen = 2 : 1 C. PHOTOCHEMICAL DECOMPOSITION Sunlight ki presence mein compound break hota hai. Example 1: 2AgCl --sunlight--> 2Ag + Cl2 Example 2: 2AgBr --sunlight--> 2Ag + Br2 ================================================== DISPLACEMENT REACTION Jab ek more reactive element, less reactive element ko uske compound se displace kar deta hai, use Displacement Reaction kehte hain. General form: A + BC → AC + B Example 1: Zn + CuSO4 → ZnSO4 + Cu Example 2: Fe + CuSO4 → FeSO4 + Cu Example 3: Zn + 2HCl → ZnCl2 + H2 IMPORTANT: Displacement reaction mein reactivity series ka concept important hai. ================================================== DOUBLE DISPLACEMENT REACTION Jab two compounds apne ions exchange karte hain aur new compounds form hote hain, use Double Displacement Reaction kehte hain. General form: AB + CD → AD + CB Example: Na2SO4 + BaCl2 → BaSO4 + 2NaCl Yahan BaSO4 ek white precipitate hai. Another example: AgNO3 + NaCl → AgCl + NaNO3 AgCl = White precipitate ================================================== PRECIPITATION REACTION Jab do solutions ki reaction se ek insoluble solid substance form hota hai, use Precipitation Reaction kehte hain. Example: Na2SO4 + BaCl2 → BaSO4 + 2NaCl BaSO4 = White precipitate Another example: AgNO3 + NaCl → AgCl + NaNO3 AgCl = White precipitate ================================================== OXIDATION Oxidation ka simple meaning: Addition of oxygen OR Removal of hydrogen Example 1: 2Cu + O2 → 2CuO Copper mein oxygen add hua. Example 2: 2Mg + O2 → 2MgO Magnesium oxidised hua. ================================================== REDUCTION Reduction ka simple meaning: Removal of oxygen OR Addition of hydrogen Example: CuO + H2 → Cu + H2O CuO se oxygen remove hua. Therefore CuO is reduced to Cu. ================================================== REDOX REACTION Jab oxidation aur reduction ek hi reaction mein simultaneously hote hain, use Redox Reaction kehte hain. Example: CuO + H2 → Cu + H2O CuO → Cu Reduction H2 → H2O Oxidation Therefore, this is a Redox Reaction. ================================================== EXOTHERMIC REACTION Jis chemical reaction mein heat/energy release hoti hai, use Exothermic Reaction kehte hain. Example 1: Respiration C6H12O6 + 6O2 → 6CO2 + 6H2O + Energy Example 2: CH4 + 2O2 → CO2 + 2H2O + Heat Example 3: CaO + H2O → Ca(OH)2 + Heat REMEMBER: Exothermic = Heat release ================================================== ENDOTHERMIC REACTION Jis reaction mein energy absorb hoti hai, use Endothermic Reaction kehte hain. Example: CaCO3 --heat--> CaO + CO2 Is reaction ke liye heat required hoti hai. REMEMBER: Endothermic = Heat absorbed ================================================== CORROSION Metals ka air, moisture ya other substances ke saath reaction karke gradually damage hona Corrosion kehlata hai. Example: Iron + Oxygen + Water → Rust Rust mainly hydrated iron(III) oxide hota hai. Rusting ke liye zaroori conditions: Oxygen Water/Moisture CORROSION KO PREVENT KAISE KAREIN? Painting Oiling Greasing Galvanisation Alloying ================================================== RANCIDITY Oil aur fats ka oxygen ke saath oxidation hone ke karan food ka taste aur smell kharab ho jata hai. Is process ko Rancidity kehte hain. RANCIDITY KO PREVENT KAISE KAREIN? Food ko airtight container mein rakhein. Refrigeration karein. Antioxidants use karein. Food packets mein nitrogen gas fill ki jaati hai. Example: Chips packets mein nitrogen gas fill ki jaati hai taaki oxidation slow ho aur rancidity prevent ho. ================================================== IMPORTANT NCERT REACTIONS Magnesium burning: 2Mg + O2 → 2MgO Type: Combination + Oxidation Quicklime + Water: CaO + H2O → Ca(OH)2 + Heat Type: Combination + Exothermic Calcium carbonate decomposition: CaCO3 --heat--> CaO + CO2 Type: Thermal Decomposition Lead nitrate decomposition: 2Pb(NO3)2 --heat--> 2PbO + 4NO2 + O2 Type: Thermal Decomposition Silver chloride decomposition: 2AgCl --sunlight--> 2Ag + Cl2 Type: Photochemical Decomposition Zinc + Copper sulphate: Zn + CuSO4 → ZnSO4 + Cu Type: Displacement Iron + Copper sulphate: Fe + CuSO4 → FeSO4 + Cu Type: Displacement Sodium sulphate + Barium chloride: Na2SO4 + BaCl2 → BaSO4 + 2NaCl Type: Double Displacement + Precipitation Copper oxide + Hydrogen: CuO + H2 → Cu + H2O Type: Redox Reaction Zinc + Hydrochloric acid: Zn + 2HCl → ZnCl2 + H2 Type: Displacement ================================================== QUICK REVISION Combination: Many reactants → One product Decomposition: One reactant → Many products Displacement: One element displaces another element. Double Displacement: Exchange of ions between two compounds. Oxidation: Addition of Oxygen / Removal of Hydrogen Reduction: Removal of Oxygen / Addition of Hydrogen Redox: Oxidation + Reduction together Exothermic: Heat is released. Endothermic: Heat is absorbed. Corrosion: Gradual damage of metals. Rancidity: Oxidation of fats and oils causing bad smell and taste. ================================================== MOST IMPORTANT EQUATIONS FOR EXAM 2Mg + O2 → 2MgO CaO + H2O → Ca(OH)2 + Heat CaCO3 --heat--> CaO + CO2 2Pb(NO3)2 --heat--> 2PbO + 4NO2 + O2 2H2O --electricity--> 2H2 + O2 2AgCl --sunlight--> 2Ag + Cl2 2AgBr --sunlight--> 2Ag + Br2 Zn + CuSO4 → ZnSO4 + Cu Fe + CuSO4 → FeSO4 + Cu Zn + 2HCl → ZnCl2 + H2 Na2SO4 + BaCl2 → BaSO4 + 2NaCl AgNO3 + NaCl → AgCl + NaNO3 CuO + H2 → Cu + H2O C6H12O6 + 6O2 → 6CO2 + 6H2O + Energy CH4 + 2O2 → CO2 + 2H2O + Heat

ACIDS Acids are substances which produce H+ ions in aqueous solution. Simple meaning: Acid wo substance hai jo water mein dissolve hone par H+ ions produce karta hai. Examples: HCl = Hydrochloric acid H2SO4 = Sulphuric acid HNO3 = Nitric acid CH3COOH = Acetic acid ================================================== BASES Bases are substances which produce OH- ions in aqueous solution. Simple meaning: Base wo substance hai jo water mein dissolve hone par OH- ions produce karta hai. Examples: NaOH = Sodium hydroxide KOH = Potassium hydroxide Ca(OH)2 = Calcium hydroxide Mg(OH)2 = Magnesium hydroxide ================================================== INDICATORS Indicators are substances which tell us whether a solution is acidic or basic by showing a change in colour or smell. IMPORTANT INDICATORS: Litmus Methyl orange Phenolphthalein Turmeric Olfactory indicators A. LITMUS Acid: Blue litmus → Red Base: Red litmus → Blue B. METHYL ORANGE Acidic solution → Red Basic solution → Yellow C. PHENOLPHTHALEIN Acidic solution → Colourless Basic solution → Pink D. TURMERIC Base ke contact mein turmeric → Reddish-brown ================================================== OLFACTORY INDICATORS Aise indicators jinki smell acidic/basic medium mein change ho jaati hai, unhe olfactory indicators kehte hain. Examples: Onion Vanilla essence Clove oil ================================================== PROPERTIES OF ACIDS Acids generally: Sour taste dete hain. Blue litmus ko red karte hain. H+ ions produce karte hain. Metals ke saath reaction karke hydrogen gas produce kar sakte hain. Bases ke saath reaction karke salt + water banate hain. Carbonates ke saath reaction karke CO2 gas produce karte hain. IMPORTANT: Laboratory acids ko taste nahi karna chahiye. ================================================== PROPERTIES OF BASES Bases generally: Bitter taste hote hain. Soapy/slippery feel de sakte hain. Red litmus ko blue karte hain. OH- ions produce karte hain. Acids ke saath reaction karke salt + water banate hain. ================================================== ACID + METAL REACTION Acid + Metal → Salt + Hydrogen gas Example 1: Zn + 2HCl → ZnCl2 + H2 Zinc + Hydrochloric acid → Zinc chloride + Hydrogen Example 2: Mg + 2HCl → MgCl2 + H2 Example 3: 2Al + 6HCl → 2AlCl3 + 3H2 IMPORTANT: Hydrogen gas ko test karne par "pop sound" mil sakti hai. ================================================== ACID + METAL CARBONATE Acid + Metal Carbonate → Salt + Water + CO2 Example: Na2CO3 + 2HCl → 2NaCl + H2O + CO2 Sodium carbonate + Hydrochloric acid → Sodium chloride + Water + Carbon dioxide ================================================== ACID + METAL HYDROGENCARBONATE Acid + Metal Hydrogencarbonate → Salt + Water + CO2 Example: NaHCO3 + HCl → NaCl + H2O + CO2 Sodium hydrogencarbonate + Hydrochloric acid → Sodium chloride + Water + Carbon dioxide ================================================== TEST FOR CO2 Carbon dioxide gas ko lime water mein pass karne par lime water milky ho jata hai. Reaction: Ca(OH)2 + CO2 → CaCO3 + H2O CaCO3 = Calcium carbonate It makes lime water milky. EXCESS CO2 pass karne par: CaCO3 + CO2 + H2O → Ca(HCO3)2 Isse milkiness disappear ho sakti hai. ================================================== ACID + BASE Acid + Base → Salt + Water Is reaction ko NEUTRALISATION REACTION kehte hain. Example: HCl + NaOH → NaCl + H2O Hydrochloric acid + Sodium hydroxide → Sodium chloride + Water Another example: H2SO4 + 2NaOH → Na2SO4 + 2H2O ================================================== ACID + METAL OXIDE Acid + Metal Oxide → Salt + Water Example: CuO + 2HCl → CuCl2 + H2O Copper oxide + Hydrochloric acid → Copper chloride + Water Another example: MgO + 2HCl → MgCl2 + H2O ================================================== BASE + NON-METALLIC OXIDE Base + Non-metallic oxide → Salt + Water Example: Ca(OH)2 + CO2 → CaCO3 + H2O Calcium hydroxide + Carbon dioxide → Calcium carbonate + Water This shows that non-metallic oxides are generally acidic in nature. ================================================== WHAT HAPPENS WHEN ACID DISSOLVES IN WATER? Acids produce H+ ions in water. Example: HCl + H2O → H3O+ + Cl- H+ ion does not exist freely in water. It combines with H2O to form H3O+ (hydronium ion). ================================================== WHAT HAPPENS WHEN BASE DISSOLVES IN WATER? Bases produce OH- ions in aqueous solution. Example: NaOH → Na+ + OH- KOH → K+ + OH- ================================================== IMPORTANCE OF WATER FOR ACIDS Acidic behaviour water ki presence mein show hota hai because acid produces ions in aqueous solution. Example: HCl + H2O → H3O+ + Cl- Dry HCl gas dry litmus paper ka colour change nahi karti because water is absent. ================================================== pH SCALE pH scale kisi solution ki acidic ya basic nature ko measure karti hai. pH scale: 0 to 14 pH < 7 = Acidic pH = 7 = Neutral pH > 7 = Basic Examples: pH 1 → Strong acid pH 3 → Acidic pH 7 → Neutral pH 9 → Basic pH 14 → Strong base IMPORTANT: Lower pH = More acidic Higher pH = More basic ================================================== IMPORTANCE OF pH IN DAILY LIFE A. DIGESTION Our stomach produces hydrochloric acid (HCl). Excess acid causes indigestion. Antacids are used to neutralise excess acid. Example: Mg(OH)2 + 2HCl → MgCl2 + 2H2O ================================================== B. TOOTH DECAY Tooth enamel starts getting damaged when mouth ka pH approximately 5.5 se below ho jata hai. Toothpaste generally basic nature ka hota hai, so it helps neutralise acids in the mouth. ================================================== C. SOIL pH Plants require a suitable pH for proper growth. If soil is too acidic: Farmers can add substances such as quicklime/slaked lime to reduce acidity. ================================================== D. STING OF BEE Bee sting contains acidic substances. Baking soda (sodium hydrogencarbonate) can help neutralise the acid. NaHCO3 is a mild base. ================================================== SALTS Salt generally acid aur base ki reaction se form hota hai. Example: HCl + NaOH → NaCl + H2O NaCl = Sodium chloride Other examples: Na2SO4 = Sodium sulphate KCl = Potassium chloride CaCO3 = Calcium carbonate NH4Cl = Ammonium chloride ================================================== COMMON SALT Common salt = Sodium chloride Formula: NaCl It is obtained from seawater and salt deposits. ================================================== CHLOR-ALKALI PROCESS Brine = concentrated aqueous solution of sodium chloride. Electrolysis of brine gives: Sodium hydroxide + Chlorine + Hydrogen Equation: 2NaCl + 2H2O → 2NaOH + Cl2 + H2 Products: NaOH = Sodium hydroxide Cl2 = Chlorine H2 = Hydrogen ================================================== BLEACHING POWDER Formula: CaOCl2 Name: Calcium oxychloride Preparation: Ca(OH)2 + Cl2 → CaOCl2 + H2O Uses: Disinfecting drinking water Bleaching cotton and linen Bleaching wood pulp Used in paper industry ================================================== BAKING SODA Chemical name: Sodium hydrogencarbonate Formula: NaHCO3 On heating: 2NaHCO3 → Na2CO3 + H2O + CO2 Uses: Baking powder Antacid Fire extinguishers ================================================== BAKING POWDER Baking powder contains: Baking soda + Mild edible acid Common acid: Tartaric acid On heating, CO2 is produced. NaHCO3 + H+ → Salt + H2O + CO2 CO2 makes the cake/bread soft and spongy. ================================================== WASHING SODA Chemical name: Sodium carbonate decahydrate Formula: Na2CO3.10H2O Preparation: 2NaHCO3 → Na2CO3 + H2O + CO2 Then: Na2CO3 + 10H2O → Na2CO3.10H2O Uses: Cleaning agent Removing permanent hardness of water Manufacturing glass Manufacturing soap and paper ================================================== PLASTER OF PARIS Chemical name: Calcium sulphate hemihydrate Formula: CaSO4.1/2H2O Preparation: CaSO4.2H2O --heat--> CaSO4.1/2H2O + 3/2H2O Gypsum: CaSO4.2H2O Plaster of Paris: CaSO4.1/2H2O When mixed with water: CaSO4.1/2H2O + 3/2H2O → CaSO4.2H2O Uses: Making casts for fractured bones Making statues Making decorative materials Making moulds ================================================== WATER OF CRYSTALLISATION The fixed number of water molecules present in one formula unit of a salt is called Water of Crystallisation. Example: CuSO4.5H2O Copper sulphate crystals contain 5 water molecules. On heating: CuSO4.5H2O --heat--> CuSO4 + 5H2O Blue copper sulphate crystals become white. Adding water again: CuSO4 + 5H2O → CuSO4.5H2O Blue colour returns. ================================================== IMPORTANT SALTS AND THEIR FORMULAS Common Salt: NaCl Baking Soda: NaHCO3 Washing Soda: Na2CO3.10H2O Bleaching Powder: CaOCl2 Plaster of Paris: CaSO4.1/2H2O Gypsum: CaSO4.2H2O ================================================== IMPORTANT REACTIONS - CHAPTER 2 Zn + 2HCl → ZnCl2 + H2 Mg + 2HCl → MgCl2 + H2 Na2CO3 + 2HCl → 2NaCl + H2O + CO2 NaHCO3 + HCl → NaCl + H2O + CO2 Ca(OH)2 + CO2 → CaCO3 + H2O CaCO3 + CO2 + H2O → Ca(HCO3)2 HCl + NaOH → NaCl + H2O H2SO4 + 2NaOH → Na2SO4 + 2H2O CuO + 2HCl → CuCl2 + H2O 2NaHCO3 → Na2CO3 + H2O + CO2 2NaCl + 2H2O → 2NaOH + Cl2 + H2 Ca(OH)2 + Cl2 → CaOCl2 + H2O CaSO4.2H2O --heat--> CaSO4.1/2H2O + 3/2H2O CaSO4.1/2H2O + 3/2H2O → CaSO4.2H2O ================================================== ONE-SHOT REVISION Acid: Produces H+ / H3O+ ions in water. CLASS 10 SCIENCE CHAPTER 3 - METALS AND NON-METALS FULL NOTES ================================================== 1. METALS ⚙️ Metals are generally hard, lustrous, malleable, ductile and good conductors of heat and electricity. Examples: Iron (Fe) Copper (Cu) Aluminium (Al) Zinc (Zn) Magnesium (Mg) Sodium (Na) Potassium (K) Gold (Au) Silver (Ag) ================================================== 2. PHYSICAL PROPERTIES OF METALS 🔩 1. Lustrous: Metals generally have a shiny surface. Example: Gold and silver are lustrous. 2. Hard: Most metals are hard. Exception: Sodium and potassium are soft metals. 3. Malleability: Metals can be beaten into thin sheets. Example: Gold and aluminium are highly malleable. 4. Ductility: Metals can be drawn into thin wires. Example: Copper and aluminium are ductile. 5. Good conductors: Metals generally conduct heat and electricity. Example: Copper and aluminium are used in electrical wires. 6. Sonorous: Metals produce a ringing sound when struck. ================================================== 3. EXCEPTIONS IN METALS ⚠️ Mercury (Hg): It is liquid at room temperature. Sodium (Na) and Potassium (K): They are very soft and can be cut with a knife. Gallium: It can melt in the palm because of its low melting point. ================================================== 4. NON-METALS 🧪 Non-metals generally do not show the properties of metals. Examples: Carbon (C) Sulphur (S) Oxygen (O) Nitrogen (N) Phosphorus (P) Chlorine (Cl) Bromine (Br) Iodine (I) ================================================== 5. PHYSICAL PROPERTIES OF NON-METALS 🌿 1. Generally dull. 2. Generally brittle. 3. Generally poor conductors of heat and electricity. 4. Not malleable. 5. Not ductile. 6. Not sonorous. IMPORTANT EXCEPTIONS: Graphite is a good conductor of electricity. Iodine is lustrous. Diamond is very hard. Bromine is a liquid non-metal. ================================================== 6. REACTION OF METALS WITH OXYGEN 🔥 Metals react with oxygen to form metal oxides. General reaction: Metal + Oxygen → Metal Oxide Example 1: 2Mg + O2 → 2MgO Example 2: 4Na + O2 → 2Na2O Example 3: 2Cu + O2 → 2CuO ================================================== 7. NATURE OF METAL OXIDES 🧪 Most metal oxides are BASIC in nature. Example: MgO + 2HCl → MgCl2 + H2O Some metal oxides are AMPHOTERIC. Amphoteric oxides react with both acids and bases. Important examples: Aluminium oxide (Al2O3) Zinc oxide (ZnO) Example with acid: ZnO + 2HCl → ZnCl2 + H2O Example with base: ZnO + 2NaOH → Na2ZnO2 + H2O ================================================== 8. REACTION OF NON-METALS WITH OXYGEN 🔥 Non-metals react with oxygen to form non-metal oxides. Example: C + O2 → CO2 S + O2 → SO2 Most non-metal oxides are acidic in nature. Example: CO2 + H2O → H2CO3 SO2 + H2O → H2SO3 ================================================== 9. REACTION OF METALS WITH WATER 💧 Different metals react with water differently. Potassium and sodium react very vigorously with cold water. Example: 2Na + 2H2O → 2NaOH + H2 + Heat Potassium: 2K + 2H2O → 2KOH + H2 + Heat Calcium reacts less violently: Ca + 2H2O → Ca(OH)2 + H2 Magnesium reacts with hot water: Mg + 2H2O → Mg(OH)2 + H2 Iron reacts with steam: 3Fe + 4H2O → Fe3O4 + 4H2 ================================================== 10. REACTION OF METALS WITH ACIDS 🧪 Metals above hydrogen in the reactivity series generally react with dilute acids to produce salt and hydrogen gas. General reaction: Metal + Acid → Salt + Hydrogen Example 1: Zn + 2HCl → ZnCl2 + H2 Example 2: Mg + 2HCl → MgCl2 + H2 Example 3: Fe + 2HCl → FeCl2 + H2 IMPORTANT: Copper does not react with dilute HCl because copper is below hydrogen in the reactivity series. ================================================== 11. REACTION OF METALS WITH BASES ⚡ Some metals react with strong bases. Example: Zinc + Sodium hydroxide: Zn + 2NaOH → Na2ZnO2 + H2 Aluminium also reacts with strong bases. 2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2 ================================================== 12. REACTION OF METALS WITH SALT SOLUTIONS 🔄 A more reactive metal can displace a less reactive metal from its salt solution. Example: Fe + CuSO4 → FeSO4 + Cu Iron is more reactive than copper. Another example: Zn + CuSO4 → ZnSO4 + Cu Zinc is more reactive than copper. But: Cu + ZnSO4 → No reaction Because copper is less reactive than zinc. ================================================== 13. REACTIVITY SERIES ⭐ The arrangement of metals in decreasing order of their reactivity is called the Reactivity Series. Most reactive ↓ K Na Ca Mg Al Zn Fe Pb H Cu Hg Ag Au ↓ Least reactive IMPORTANT: Metals above hydrogen can generally displace hydrogen from dilute acids. ================================================== 14. EXTRACTION OF METALS ⛏️ Metals are extracted from their ores. Steps generally involved: 1. Concentration of ore 2. Conversion of ore into oxide 3. Reduction of metal oxide 4. Refining of metal ================================================== 15. EXTRACTION ACCORDING TO REACTIVITY ⚙️ A. Highly reactive metals: K, Na, Ca, Mg, Al These are extracted by ELECTROLYSIS. Example: 2NaCl → 2Na + Cl2 B. Moderately reactive metals: Zn, Fe, Pb, etc. Their ores are generally converted into oxides and then reduced using carbon or other reducing agents. Example: ZnO + C → Zn + CO C. Low reactive metals: Cu, Hg, Ag, Au They can often be obtained by heating their ores or through other suitable processes. ================================================== 16. ROASTING 🔥 Sulphide ores are heated strongly in the presence of excess air. Example: 2ZnS + 3O2 → 2ZnO + 2SO2 ================================================== 17. CALCINATION 🔥 Carbonate ores are heated strongly in limited or no air. Example: ZnCO3 → ZnO + CO2 ================================================== 18. REDUCTION 🧲 Metal oxide is reduced to metal. Example: ZnO + C → Zn + CO Here: ZnO → Zn = Reduction ================================================== 19. THERMITE REACTION 🔥 Aluminium is used as a reducing agent. Example: Fe2O3 + 2Al → 2Fe + Al2O3 + Heat This reaction produces a large amount of heat. Uses: It is used for welding railway tracks. ================================================== 20. REFINING OF METALS ✨ The process of obtaining pure metal from an impure metal is called Refining. Electrolytic refining is used for metals such as: Copper Zinc Silver Gold ================================================== 21. ELECTROLYTIC REFINING OF COPPER 🔋 In electrolytic refining: Anode = Impure copper Cathode = Pure copper Electrolyte = Copper sulphate solution When electric current is passed: Copper from the anode dissolves and gets deposited on the cathode. Impurities settle at the bottom as anode mud. ================================================== 22. IONIC COMPOUNDS ⚡ Ionic compounds are formed by transfer of electrons from one atom to another. Example: Formation of NaCl: Na → Na+ + e- Cl + e- → Cl- Then: Na+ + Cl- → NaCl Sodium loses one electron. Chlorine gains one electron. ================================================== 23. PROPERTIES OF IONIC COMPOUNDS 🧂 1. They are generally hard. 2. They have high melting and boiling points. 3. They are generally soluble in water. 4. They conduct electricity in molten state. 5. They conduct electricity in aqueous solution. 6. They do not conduct electricity in solid state. WHY? Because ions cannot move freely in solid state. ================================================== 24. OCCURRENCE OF METALS 🌍 Metals occur in the Earth's crust in two forms: 1. Minerals 2. Ores Mineral: Naturally occurring substance containing metal or its compounds. Ore: A mineral from which metal can be extracted profitably. ================================================== 25. CORROSION 🛡️ The gradual destruction of metals due to reaction with air, moisture or chemicals is called corrosion. Example: Rusting of iron. Iron + Oxygen + Water → Rust Rust is mainly hydrated iron(III) oxide. ================================================== 26. PREVENTION OF CORROSION 🛡️ Corrosion can be prevented by: 1. Painting 2. Oiling 3. Greasing 4. Galvanisation 5. Alloying ================================================== 27. GALVANISATION 🧤 Coating iron or steel with a layer of zinc to prevent rusting is called galvanisation. Zinc protects iron from corrosion. ================================================== 28. ALLOYS 🔧 An alloy is a homogeneous mixture of two or more metals, or a metal and a non-metal. Examples: Brass = Copper + Zinc Bronze = Copper + Tin Solder = Lead + Tin Stainless steel = Iron + Chromium + Nickel + Carbon ================================================== 29. WHY ARE ALLOYS USED? 💡 Alloys generally have better properties than pure metals. LIMITATION OF DOBEREINER'S TRIADS ❌ Dobereiner could identify only a few triads. All known elements could not be arranged into triads. Therefore, this classification was not suitable for all elements. ================================================== 4. NEWLANDS' LAW OF OCTAVES 🎵 John Newlands proposed the Law of Octaves in 1866. He arranged elements in increasing order of atomic masses. He observed that every eighth element had properties similar to the first element. It was called the Law of Octaves because it was similar to the eight notes of music. Example: Li, Be, B, C, N, O, F, Na Li and Na have similar properties. ================================================== 5. LIMITATIONS OF NEWLANDS' LAW ❌ 1. It was applicable only up to calcium. 2. New elements discovered later could not be fitted properly. 3. Some dissimilar elements were placed together. 4. MENDELEEV'S PERIODIC TABLE ⭐ Dmitri Ivanovich Mendeleev proposed the Periodic Table in 1869. He arranged elements in increasing order of their atomic masses. MENDELEEV'S PERIODIC LAW: "The properties of elements are a periodic function of their atomic masses." Meaning: When elements are arranged in increasing order of atomic masses, their properties repeat after certain intervals. ================================================== 7. ACHIEVEMENTS OF MENDELEEV'S PERIODIC TABLE 🏆 1. Elements with similar properties were placed in the same group. 2. He left gaps for undiscovered elements. 3. He predicted the properties of undiscovered elements. 4. New elements discovered later fitted into the gaps. Example: Mendeleev predicted an element called "eka-aluminium". Later, it was discovered as Gallium. ================================================== 8. LIMITATIONS OF MENDELEEV'S PERIODIC TABLE ⚠️ 1. Position of hydrogen was not fixed properly. 2. Isotopes could not be given separate positions. 3. Some elements had to be placed in an order that did not strictly follow atomic mass. Example: Cobalt and Nickel. Cobalt atomic mass ≈ 58.9 Nickel atomic mass ≈ 58.7 Yet their order was based on properties. ================================================== SAMPLE PAPER QUESTION 📝 Q. He predicted the properties of elements that had not yet been discovered. ================================================== 9. MODERN PERIODIC LAW 🔬 Modern Periodic Law was given by Henry Moseley. MODERN PERIODIC LAW: "The properties of elements are a periodic function of their atomic numbers." IMPORTANT: Mendeleev → Atomic Mass Modern Periodic Table → Atomic Number ================================================== 10. MODERN PERIODIC TABLE 📊 Modern Periodic Table contains: 18 Groups 7 Periods Groups = Vertical columns Periods = Horizontal rows ================================================== 11. GROUPS 📌 There are 18 vertical columns called Groups. Elements in the same group generally have similar chemical properties because they have the same number of valence electrons. Example: Group 1: Li Na K All have 1 valence electron. ================================================== 12. PERIODS 📌 There are 7 horizontal rows called Periods. The period number tells the number of electron shells present in the atom. Example: Period 2 elements have 2 electron shells. Period 3 elements have 3 electron shells. ================================================== 13. VALENCE ELECTRONS ⚡ Electrons present in the outermost shell are called valence electrons. VALENCY ⭐ The combining capacity of an element is called its valency. For elements having 1, 2, 3 or 4 valence electrons: Valency = Number of valence electrons For elements having more than 4 valence electrons: Valency = 8 - Number of valence electrons Examples: Na = 2,8,1 Valency = 1 Mg = 2,8,2 Valency = 2 Al = 2,8,3 Valency = 3 C = 2,4 Valency = 4 N = 2,5 Valency = 3 O = 2,6 Valency = 2 Cl = 2,8,7 Valency = 1 Ne = 2,8 Valency = 0 ================================================== SAMPLE PAPER QUESTION 📝 Q. ATOMIC SIZE 📏 Atomic size means the distance between the centre of the nucleus and the outermost shell of an atom.
